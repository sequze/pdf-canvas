# Shared Library

Общая библиотека для микросервисов PdfCanvas. Содержит переиспользуемые компоненты для работы с RabbitMQ, Redis, конфигурацией и общими моделями данных.

---

## 📦 Содержимое

### Модули

- **`async_rmq.py`** — Асинхронные клиенты для RabbitMQ
- **`broker_messages.py`** — Модели сообщений для обмена между сервисами
- **`config.py`** — Конфигурационные классы и настройка логирования
- **`exceptions.py`** — Пользовательские исключения
- **`redis.py`** — Клиенты для работы с Redis
- **`rmq_topology.py`** — Настройка топологии RabbitMQ (очереди, exchanges, bindings)
- **`db/unit_of_work.py`** — Паттерн Unit of Work для работы с базой данных
